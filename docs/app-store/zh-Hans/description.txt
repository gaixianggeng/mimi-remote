Mimi Remote 是一款原生移动开发工作台，用来连接你拥有或获授权使用的计算机开发环境。

连接后，你可以创建或继续编码会话、查看代码修改、为每个会话选择受限操作的处理方式，并在所有命令仍由你控制的计算机执行的前提下继续开发工作。

主要功能：
- 浏览、搜索、创建和继续编码会话
- 查看结构化回复、推理过程、代码块、图片和 Diff
- 为每个会话选择权限档位；在需要审批的档位中，受限操作运行前进行确认（新会话默认完全访问）
- 查看 Git 状态并管理分支与 worktree
- 使用文字、图片和可选语音输入
- 为不同计算机保存相互隔离的连接档案
- 通过局域网、私有网络、HTTPS、自建点对点连接或可选的 Mimi 托管连接访问计算机

App 与电脑端免费开源，局域网、Tailscale 和自建 Tailcat 连接继续免费。Mimi Remote 不在移动设备上下载或执行代码，不提供模型、第三方账号、云端代码执行或项目托管。命令与项目内容由你自己的电脑处理。

可选的「Mimi 托管连接」让你不在同一 Wi-Fi 也能连上自己的电脑，无需安装其他联网工具。每个订阅最多支持 3 台电脑、5 台手机或平板，可在 App 内移除设备。能直连时点对点传输，否则经 Mimi 运营的中继转发端到端加密数据包。开发者无法读取代码、对话或文件内容；服务会处理订阅、设备授权、连接结果和必要的网络元数据，详见隐私政策。消息通知也使用开发者运营的推送服务。

无需 Mimi 账号。同一 Apple ID 可以恢复订阅权益，但不会同步连接地址、私钥或电脑访问凭据；新手机或平板需要对每台电脑重新接入。

使用要求：
- 一台已安装 Mimi 配套服务和兼容开发运行时的计算机
- 移动设备能够通过网络访问所配置的计算机
- 只连接你拥有或已获明确授权访问的设备与项目

Mimi Remote 是独立开发的开源工具，不隶属于任何兼容工具提供方，也不代表其官方产品。

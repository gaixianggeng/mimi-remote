# GitHub #400 设置链路 UI 验收清单

## 目标

本清单用于验收“我的”和“设备”入口下的设置链路。按用户 2026-09-09 的最新反馈，iPad 使用实际窗口宽度决定导航：宽度低于 860pt 或紧凑宽度使用四 Tab，其余保留侧栏，包含大屏 iPad Pro 竖屏。iPhone 始终使用四 Tab。高度变化由内容排布与滚动适配，不单独触发导航切换。代码审查只确认实现规则是否存在。需要画面、交互或旋转证据的项目必须在固定测试设备上另行验证。

统一基线如下：

- 普通行最小高度为 52pt。
- 带说明的行最小高度为 76pt。
- 辅助功能字号下所有行的最小高度为 76pt，并允许内容自然增高。
- 行左右内边距为 16pt。
- 普通设置图标使用 28pt 槽位、18pt 图标和 12pt 图文间距。
- 普通图标使用中性色。成功、警告等状态使用主题语义色。
- 普通详情页内容最大宽度为 720pt，组间距为 24pt。
- 紧凑 Tab 下的表单和滚动内容必须避开底部栏。

## 代码审查结论

以下规则已在代码中收敛：

- `SettingsRowStyle` 为 `Form` 设置 52pt 基础行高，并在辅助功能字号下切换为 76pt。
- `settingsRow(.descriptive)` 为说明行设置 76pt 下限。所有行只使用最小高度，没有固定内容高度。
- `settingsDetailPage()` 统一 720pt 最大宽度、Form 底部滚动留白和紧凑 Tab 的底栏避让。
- `themedSettingsForm` 统一使用 24pt 组间距。
- `settingsScrollContent()` 统一法律页和诊断页的 720pt 最大宽度、16pt 横向内边距和 24pt 底部留白。
- `SettingsValueLabel`、`ConnectionRowLabel`、选项行、能力行和测速阶段行已使用 28pt 图标槽、18pt 普通图标及 12pt 图文间距。
- `ConnectionRowLabel` 直接复用 `SettingsValueLabel`，连接入口与其它设置入口共享同一套行布局。
- 安装平台、测速线路和基准测试选项使用共享内存状态。页面因横竖屏布局切换而重建时可以复用这些选择。
- iPad 顶部 Tab 选中“我的”或“设备”时不再套工作台外层 `NavigationStack`，设置路径只由自身的类型化导航栈管理。
- 重命名 Sheet 已使用标准行高、主题字体与颜色及 720pt 详情宽度。

# 桌面端能力对等

Windows 原生客户端使用 WinUI 3，继续调用和 Mac 相同的 agentd。下表区分已实现的入口和仍需验收的用户链路；实现不等于正式发布。Refs #974 #977 #978 #979 #980。

| 能力 | Mac | Windows 原生客户端 | 验收或发布边界 |
| --- | --- | --- | --- |
| 概览、启停服务 | 已有 | 已实现 | 退出客户端不停止独立后台服务 |
| 跨渠道会话首页 | 已有 | 已实现只读列表 | Codex、Claude 和原生 DeepSeek；渠道/项目筛选、已加载记录搜索、日期分组与状态。连接不带具名 session，不打开、恢复或接管会话。Refs #1021 |
| 首次选择代码目录 | 已有 | 已实现 | 通过 `workspace --root` 更新已有配置，保留 Token、配对与其他模块；首次安装联调由 #979 验收 |
| 配对二维码 | 已有 | 已实现 | Tailcat、Tailscale、局域网；到期及离开页面清除；真实手机配对仍需验收 |
| Mimi、默认、自建中转 | 已有 | 已实现 | 共用 `tailcat relay set` 和契约夹具；官方准入真实链路仍需验收 |
| Codex、Claude 开关 | 已有 | 已实现 | 调用现有 CLI，重启后从运行中的服务核对；失败使用 CLI 事务恢复 |
| DeepSeek Harness | 已有 | 已实现 | 手动粘贴启动链接，经 stdin 传递并立即清除输入框；不安装、启动或登录 Harness；重载失败明确提示保留的配置 |
| Tailscale、局域网开关 | 已有 | 已实现 | 运行态确认；LAN 仍受专用网络和防火墙规则检查，不绕过系统策略 |
| 额度 | 已有 | 已实现 | 只显示运行时实际提供的窗口、余额和方案；缺失不显示为 100% |
| 诊断与最近日志 | 已有 | 已实现 | 界面内显示，不打开终端；详细日志管理仍待完善 |
| 登录启动 | 已有 | 已实现 | 仅控制当前用户的原生客户端启动项，后台服务独立；旧托盘启动项迁移由 #979 统一处理 |
| 系统通知 | 已有 | 已实现 | Windows App SDK 本地通知；可关闭，服务连续两次健康检查失败时通知；Windows 10 和通知激活仍需实测 |
| 软件更新 | 已有 | 已实现安全入口 | 仅官方 `vX.Y.Z` 已上传的签名安装包及摘要；SHA-256、信任链、同证书校验。当前未签名预览版禁止自动安装，正式签名在 #980，版本注入与安装器切换在 #979 |
| Homebrew 接管 | 已有 | 不适用 | Windows 使用按用户安装的 Inno Setup 和计划任务 |
| 照片与 macOS 隐私权限 | 已有 | 不适用 | 属于 macOS 权限与媒体能力，无对应 Windows 设置迁移 |
| Codex 前门 | 已有 | 不适用 | macOS 专属共享运行时机制，不向 Windows 复制私有接入方式 |

## 验证方式

- Go 目录事务测试覆盖身份/未知字段保留、无效目录不写入、恢复时保留其他模块新改动、拒绝过期恢复。
- C# 契约测试覆盖模块运行态不匹配、事务恢复失败、额度缺失、正式 Release 来源与上传状态、摘要不匹配和文件名替换。
- 会话测试覆盖原生 Harness 夹具、跨渠道身份、项目切换与取消、失败保留旧记录、分页前缀不误删、连接内游标及本机凭据请求；详细边界见 [Windows 会话首页](design/gh-1021-windows-session-library.md)。
- 本地预览使用 `--debug-seed-ui`，不启动真实服务、不保存配置或配对信息。
- 首次安装到扫码打开项目、Windows 10、Narrator、DPI/多屏、升级回滚与签名安装均需按父 Issue 清单继续验收，不以预览或单元测试替代。

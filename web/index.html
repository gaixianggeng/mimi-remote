Reply and approve

Answer it. Approve it.
Stop it if you need to.

When the agent asks a question, answer it from the composer. When it wants to run a command or change files, allow it once, for the session or always for that tool — or reject it. Queue the next instruction while a turn is still running, or interrupt it.

  • Approve in place

    Allow once, for the session, or always — without leaving the thread.

  • Queue the next step

    Line up follow-ups while the current turn is still running.

  • Switch models anytime

    Pick the model, reasoning level and speed for each turn.

  • Voice, images and files

    Dictate, attach screenshots and preview files with Quick Look.

New sessions start in Full File Access, so the agent runs commands and edits files without asking each time. To confirm actions one by one, set Default permissions to Ask for Approval in the app's settings.

you'll know.

When an agent wants to run a command, change files or needs your input, a notification arrives with the session's title. Finished replies, failures and interruptions come through too — and approvals can be answered right from the notification.

On by default, and you can turn them off in the app. Only a fixed-format status leaves your computer — never your code, prompts or conversations. Session titles are filled in on your phone.

Computers and agents

One phone.
Every computer.
Every agent.

The Mac Studio at home, the MacBook you travel with, the Windows workstation at the office — each is its own saved connection, with its own token in the Keychain, and its sessions stay on that computer. Switching takes one tap.

Computers

  • macOS A menu bar app for status, quota and one-click pairing.
  • Windows A tray app and a per-user service for Windows 10 and 11.
  • Linux A desktop tray and a systemd user service.

Agents

  • Codex The main runtime: sessions, live progress, approvals, task controls and project tools.
  • Claude Code Experimental Sessions and approvals, with fewer controls than Codex.
  • DeepSeek Harness Optional. Text sessions and live progress.

Connection

Same Wi-Fi at home.
Tailscale on the go.

Mimi talks only to the computer you paired, over a trusted local network or your own Tailscale network. There's no Mimi cloud account, session hosting or application-level relay; the optional Tailcat route's transport relay is explained below. Pairing is a QR code on the computer, scanned once with your phone. Keep the computer service on a private network; don't expose it to the public Internet.

  • Same Wi-Fi

    On a trusted local network, connect directly with nothing else to set up.

  • Tailscale

    Already on a tailnet? Mimi uses it as is.

  • Tailcat Experimental

    Mac, Windows and Linux, off by default. Lets your phone reach the computer without the Tailscale app.

Every Tailcat connection first contacts a DERP relay for discovery and the initial handshake, then moves end-to-end encrypted traffic to a direct path when available; otherwise the relay keeps forwarding it. The relay processes connection metadata even when traffic later goes direct. The default relay is operated by Tailscale, not by Mimi Remote, and you can configure your own on the computer.

Compared with remote desktop and SSH

Not a remote desktop.
Not a terminal.

Mimi Remote controls agent sessions only. To operate the whole computer or an arbitrary shell from your phone, a remote desktop or SSH client is the better fit.

FAQ

Before you
install.

Do I sign in to OpenAI or Anthropic on my phone?

No. The app only connects to the computer you paired. The agent uses the Codex or Claude Code sign-in already on that computer, and Mimi Remote never handles those credentials.

Does my computer need to stay on?

Yes. The agent runs on the computer, so it has to stay awake and online while you connect.

Where are my sessions stored?

On your computer, by Codex, Claude Code or DeepSeek Harness. Mimi Remote has no cloud account and does not host sessions.

How do I connect when I'm not on the same network?

Put your phone and computer on the same private network with Tailscale. Mac, Windows and Linux computers can also try the experimental Tailcat connection described under Connection.

Does it cost anything?

The iPhone and iPad app and the computer software are free and open source, with no in-app purchases or subscriptions. Model usage counts against the Codex or Claude Code account on your computer.

How is this different from the official mobile remote features from OpenAI and Anthropic?

Each official feature serves its own agent. Mimi Remote connects to both Codex and Claude Code (and DeepSeek Harness) in one app, works with Mac, Windows and Linux computers and switches between several of them, gives you a multi-column workspace on iPad, and is fully open source. The official features change quickly, so pick whatever fits the tools and accounts you use.

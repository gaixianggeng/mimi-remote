# MIM-227 iPad ImageGen 提示词

本组 iPad 图片使用 Codex 内置 ImageGen 编辑模式生成。

```text
Create a vertical Chinese App Store promotional screenshot.

Use the supplied campaign image for the deep-plum background, green accent,
typography, translucent circles, scale, restrained perspective, lighting,
and text hierarchy. Use the supplied Debug screenshot as the exact app screen.

Render one large landscape iPad with classic silver aluminum, a very thin
black bezel, restrained shallow perspective, and a soft studio shadow.
Keep all supplied Chinese marketing copy visible and correctly spelled.
Do not invent UI, labels, icons, logos, watermarks, or extra devices.
```

四张图依次展示会话接力、多设备控制、原生客户端会话和优雅设计。第 2 张的支持说明固定为“支持 Mac 与 Linux”，不把只能作为 Codex Desktop 客户端的 Windows 描述为 `agentd` 宿主。ImageGen 会重采样界面，上传前必须再次核对界面文字、图标和控件。
